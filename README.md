## Completed Laboratory Highlights

### Lab 03 – Search Engineering
- Search algorithm implementation and evaluation.
- Benchmark comparisons and experimental results.

### Lab 05 – Robotics Sensor Control
- Sensor data analysis.
- Decision Tree and Random Forest classification.
- Rule-based controller evaluation.
- Noise robustness analysis.

### Lab 06 – Handwriting OCR Evaluation
- Handwritten prescription image processing.
- Baseline and preprocessed OCR comparison.
- Character Error Rate (CER) and edit distance evaluation.
- OCR error analysis.

### Lab 07 – Airline Tweet Sentiment Classification
- Airline tweet sentiment classification.
- Majority baseline and Multinomial Naive Bayes comparison.
- Model evaluation using accuracy, precision, recall, and F1-score.
- Confusion matrix and error analysis.

### Lab 09 – Genetic Algorithm for Medical Cost Regression
- Genetic Algorithm implementation for regression.
- Comparison with Ordinary Least Squares (OLS).
- Evaluation across multiple random seeds.
- Population-size sensitivity analysis.

### Genetic Algorithm – Delivery Route Optimisation
- Chromosome representation using delivery locations.
- Tournament selection and order crossover.
- Swap mutation and elitism.
- Route optimization using a fictional delivery-distance dataset.
- Best route and total distance evaluation.
